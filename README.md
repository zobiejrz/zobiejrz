# 👋 I'm Ben Zobrist

## 🚀 About Me

I'm a software engineer with a B.S. in Computer Science (Data Science emphasis) from Brigham Young University, graduating December 2023. I build production applications across iOS, web, and data-driven systems — I've shipped multiple apps to the App Store, contributed machine learning and data analysis work to two published research papers, and work with a toolkit spanning Swift, Python, JavaScript, and modern web frameworks.

## 💼 Experience

- **Community Coordinator**, [chessreps.com](https://chessreps.com) - Manage online community forums, resolve support inquiries, and plan community engagement events.
- **Front-End Developer**, BYU Broadcasting - Developed video player elements for the BYUtv public website, maintained Vue.js components for the site and internal tools, and built custom extensions for the Video.js and markdown-it libraries.
- **iOS Developer**, Applied Computation Lab - Built a native iOS app for a gesture-based Mandarin keyboard, designed cross-platform features, and tested/reviewed the Android implementation for architectural and UX issues.
- **QA Engineer**, BYU Continuing Education - Built and maintained automated Selenium test suites for a Learning Management System, co-authored coding standards, and wrote user documentation and release notes.


## 🌟 Featured Projects

- **[zChess Clock](http://zchessclock.app)** (Swift, SwiftUI) - Shipped Nov 2025. A flexible chess timer with a precise real-time countdown engine built on Combine and SwiftUI's timer system, a modular time-control system supporting multiple timekeeping methods, and SwiftData-backed persistence. Repo: [zobiejrz/zChessClock](https://github.com/zobiejrz/zChessClock)
- **[zChess](https://www.zchess.app)** (Swift, SwiftUI) - Shipped Oct 2025. A cross-platform chess opening/puzzle trainer for iPadOS and iOS, built on my own [zChessKit](https://www.github.com/zobiejrz/zChessKit) chess engine package. Includes a custom-written PGN parser for persisting gameplay moves, puzzles, and courses, plus Firebase Firestore/Storage integration for syncing puzzles and lessons.
- **[zChessKit](https://www.github.com/zobiejrz/zChessKit)** (Swift) - A standalone Swift package providing fast chess move generation, legality checking, and FEN/PGN parsing, published to the Swift Package Manager registry.
